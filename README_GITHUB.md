# 1. Project ULTRON — GitHub Pages Web Version

Upload the files inside this folder (`index.html`, `manifest.json`, `.nojekyll`) directly to your GitHub repository to run Project ULTRON online from anywhere on PC or Phone.

## Setup Steps (2 Minutes)
1. Upload `index.html`, `manifest.json`, `favicon.ico`, `favicon-512.png`, and `.nojekyll` to the root of your GitHub repository.
2. In your GitHub repo, go to **Settings -> Pages -> Branch -> main (/root) -> Save**.
3. Open **Firebase Console (`jarvis-f1be9`) -> Authentication -> Settings -> Authorized domains** and add `<your-username>.github.io`.
4. Ensure your Realtime Database rules match `database.rules.json`.
5. Open `https://<your-username>.github.io/<repo-name>/` on any PC or Phone and sign in with Google!
